AKASH — REEL-INSPIRED PORTFOLIO

This version uses a warm editorial layout, oversized typography, a split portrait hero,
dark selected-work section, lime timeline, responsive toolkit and animated contact button.
It is a responsive HTML/CSS/JS website (no build step or framework required).

FILES
- index.html
- style.css
- script.js
- profile.png

BEFORE PUBLISHING
1. Replace your.email@example.com with your real email.
2. Replace the LinkedIn URL with your profile URL.
3. Confirm your college name and expected graduation year.
4. Add accurate roles, dates, project screenshots and links. Do not claim skills or outcomes you cannot demonstrate.
5. The Analytics Lab entry is marked as in progress; update it when you have a completed case study.

DEPLOY
Upload these four website files to the ROOT of your GitHub repository. Keep profile.png in the same folder as index.html.
For Vercel, use Framework Preset: Other, Root Directory: ./, and leave build/output commands empty.
